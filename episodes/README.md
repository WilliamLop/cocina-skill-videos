## 2. Próximas Combinaciones de la Matriz 2×2 por Probar

- **Combinación `1B` (Formato 1 Full 9:16 + Estilo B Híbrido: Imágenes Consecutivas `0.30s` + Clips de Video `.mp4`):**
  - Usar secuencias de 2 a 3 imágenes consecutivas (`.png`) encadenadas con `L17` + sonidos de `assets/sfx/` (`knife_chop_wood.wav`, `knife_slice.wav`, `bench_scraper.wav`) para los cortes rápidos en tabla, y videos `.mp4` para fuego, salsas y payoff.
- **Combinación `2B` (Formato 2 Caricaturas Split-Screen + Estilo B Híbrido: Imágenes Consecutivas `0.30s` + Clips de Video `.mp4`):**
  - Cuando el personaje animado pique o apile ingredientes a gran velocidad, usar *jump-cuts* de imágenes consecutivas encadenadas con `L17` + SFX percusivo en la ventana inferior, y videos `.mp4` para la cocción, salsas y el cierre a Pantalla Completa.
